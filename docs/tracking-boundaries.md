# Tracking boundaries

[Documentation](README.md) · [Home](../README.md)

Track application source, packaged assets, tests, native catalog/portable project descriptor, dependency lock, agent skill and reusable support documents.

Keep these local and ignored: `.venv`, `.local`, `.calamum/generated`, bytecode/build caches, environment files, SQLite databases/journals, exports/backups, deployment descriptors, protected token bundles, credential journals and private keys. Installed credentials and active data live outside the repository. Names-only configuration examples remain tracked; real configuration does not.

Business plans, approval evidence, Polymath home and project-specific migration handoffs stay in Polymath custody. Do not copy the private home page, governing project ledgers, signed controls or production records into this portable repository.

Cleanup removes only reproducible caches. Preserve failed tests, source manifests, old proofs, local wheels, the working venv, deployment and owner data. Git dangling objects from staged revisions are not corruption and are not routinely pruned.

The source repository is public. Every push transmits reachable history as well as current files, so inspect both. Targeted pattern scanning reduces obvious disclosure risk but is not an exhaustive secret detector. Push only the reviewed branch after the requested final authorization; do not publish a release or change repository visibility.
